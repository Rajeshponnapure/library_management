# Frontend

This is the React/Vite client for the CBIT Digital Library Management System.

## Setup

```powershell
npm install
npm run dev
```

The dev server runs at:

```text
http://localhost:5173
```

Keep the FastAPI backend running at:

```text
http://127.0.0.1:8000
```

## Scripts

- `npm run dev` starts the Vite development server.
- `npm run build` creates a production build in `dist/`.
- `npm run preview` previews the production build locally.
- `npm run lint` runs ESLint.

See the root `README.md` for full project setup, backend setup, database notes, and troubleshooting.
